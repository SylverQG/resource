# 图像特征

SIFT（尺度不变特征变换）在 OpenCV 官方主包（ cv2 ）里是 收费专利算法，只在 contrib 扩展包里 。

注意安装`opencv-contrib`,将其放在了 [release](https://github.com/SylverQG/resource/releases/tag/whl-01-opencv-contrib-py3.6)

# 使用脚本下载到当前目录
```bash
python utils/download.py 第11-12章
```


只适配 Python 3.6 + 64 位 Windows

```bash
pip install opencv_python-3.4.5+contrib-cp36-cp36m-win_amd64.whl
```
